# Clothing Recommendation System

## About the Project

This is a study project developed to explore and apply concepts of Artificial Intelligence, Machine Learning, and Computer Vision.

The project consists of a clothing recommendation system based on visual features. It takes an image of a clothing item, identifies its category, and recommends other visually similar items from the dataset.

Artificial Intelligence techniques are used throughout the system. The DINOv2 model extracts visual features from images, while an SVM (Support Vector Machine) classifier identifies clothing categories. Recommendations are generated by calculating cosine similarity between the extracted feature vectors.

## Objectives

The main goal is to develop a system capable of recognizing clothing items and finding visually similar images based on their visual characteristics.

As a study project, it also provides practical experience with supervised learning, feature extraction using pre-trained models, image classification, model evaluation, and similarity calculations.

## Dataset

The project uses the [Clothes Dataset](https://www.kaggle.com/datasets/ryanbadai/clothes-dataset), available on Kaggle.

The dataset contains 7,500 images evenly distributed across 15 clothing categories, with 500 images per category.

The categories are:

- Celana_Panjang
- Celana_Pendek
- Gaun
- Hoodie
- Jaket
- Jaket_Denim
- Jaket_Olahraga

- Kaos

- Sweter

## How It Works

The system is divided into four main stages.

### 1. Visual Feature Extraction

The DINOv2 Small model, developed by Meta, is used to extract visual features from the images.

Each image is converted into a 384-dimensional numerical vector called an embedding. This vector represents visual information learned by the model during pre-training.

After extraction, the embeddings are normalized and stored for use in the following stages.

### 2. Clothing Classification

The embeddings are used as input features for an SVM classifier with an RBF kernel.

The model is trained to recognize the 15 categories in the dataset. During development, different hyperparameter configurations were evaluated, and cross-validation was used to assess the classifier's performance.

### 3. Similarity Calculation

After identifying the image category, the system compares its embedding with the embeddings stored in the dataset.

This comparison uses cosine similarity, calculated through the dot product of normalized vectors.

Higher similarity scores indicate greater visual similarity between images.

Recommendations are filtered by the predicted category, ensuring that the system only compares and recommends items belonging to the same category.

### 4. Generating Recommendations

Finally, the system selects the five images with the highest similarity scores and displays them alongside the original image.

Users can also upload images that are not part of the dataset. These images go through the same feature extraction, classification, and similarity search process.

## Model Evaluation

The classifier was evaluated using separate training and test sets, as well as five-fold stratified cross-validation (*Stratified K-Fold Cross-Validation*).

The following metrics were used:

- **Accuracy:** Measures the proportion of correctly classified samples out of the total number of samples evaluated.
- **Macro F1-score:** Calculates the average F1-score across all categories, giving equal importance to each class.

GridSearchCV was also used to test different SVM hyperparameter combinations and identify configurations with the best average performance during cross-validation.

## Running the Project

The project was developed in Google Colab and can be executed in a Python environment.

To run it:

1. Open the project notebook in Google Colab.
2. Install the required dependencies.
3. Download the dataset using KaggleHub.
4. Run the data processing and embedding extraction steps.
5. Train or load the SVM classifier.
6. Load the embeddings and image information.
7. Upload an image to obtain its classification and recommendations.

To use the system with the previously trained files, the SVM model (`svm_model.pkl`) and the embeddings file (`dinov2_embeddings.npz`) must be available.
